# VELMORA

Luxury skincare and cosmetics storefront for a fictional Indian beauty house.

**Tagline:** Your Skin. Your Ritual. Your Radiance.

Campaign imagery is art-directed for the collection. It is not photography of manufactured retail units.

## Scripts

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (typically `http://localhost:5173`).

## Stack

- React 19 + Vite
- React Router
- Client-side bag and simulated checkout (localStorage)
